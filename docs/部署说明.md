# 部署说明（公网）

系统按公网标准构建：登录限流、API Key 认证、上传白名单、参数化 SQL、代理价格隔离。
推荐部署：云服务器（1核2G 起）+ Nginx 反代 + HTTPS 证书 + systemd 守护。

## 一、服务器准备（Linux 为例）

```bash
# 安装 Python 3.12+、Node 20+、MySQL 8.0（或使用云数据库）
# 上传项目目录，例如 /opt/bs-order
```

## 二、配置

编辑 `/opt/bs-order/.env`：

```ini
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=bs
DB_PASSWORD=强密码
DB_NAME=bs_order_system
PORT=8000
JWT_SECRET=改成新的随机长字符串
COOKIE_SECURE=true        # 启用 HTTPS 后必须为 true

# 可选但推荐：多 worker 的 WebSocket 广播与共享限流
REDIS_URL=redis://127.0.0.1:6379/0

# 仅当请求确实经过 Nginx 时开启；TRUSTED_PROXIES 填反代地址
TRUST_PROXY_HEADERS=true
TRUSTED_PROXIES=127.0.0.1

# 允许的浏览器来源（同源部署可只保留正式域名）
ALLOWED_ORIGINS=https://your.domain.com

# 备份加密密钥（Fernet key，44 位 base64 urlsafe）
# 生成：python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
# 不填则从 JWT_SECRET 派生；更换 JWT_SECRET 前请先导出该密钥
BACKUP_ENCRYPTION_KEY=
```

## 三、构建与启动

```bash
cd /opt/bs-order/web
npm install && npm run build        # 生成 web/dist

cd /opt/bs-order/server
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m app.init_db     # 首次：建库建表，记录打印的管理员初始密码

# 建议先用演示数据跑一遍再清空
.venv/bin/python scripts/demo_data.py create && .venv/bin/python scripts/demo_data.py clean
```

## 四、systemd 守护

`/etc/systemd/system/bs-order.service`：

```ini
[Unit]
Description=BS Order System
After=network.target mysql.service

[Service]
WorkingDirectory=/opt/bs-order/server
ExecStart=/opt/bs-order/server/.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 2
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable --now bs-order
```

> 注意：使用 `--workers 2` 以上时必须配置 `REDIS_URL`，否则 WebSocket 广播和限流只在单个进程内生效。单 worker 可不配 Redis。
> 升级老库前先备份，并执行 `sql/migrate_v115_security.sql`（token_version / 分片会话 / 索引）。

## 五、Nginx + HTTPS

```nginx
server {
    listen 80;
    server_name your.domain.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your.domain.com;

    ssl_certificate     /etc/letsencrypt/live/your.domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your.domain.com/privkey.pem;

    client_max_body_size 8192m;          # 演示视频等大文件上传
    proxy_read_timeout 600s;             # AI 生成需求书耗时较长

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

证书：`certbot --nginx -d your.domain.com`

## 七、v1.16 升级提示（已有环境）

1. 安装新增依赖：
   ```bash
   cd /opt/bs-order/server
   .venv/bin/pip install -r requirements.txt      # 新增 openpyxl、确认 reportlab 已装
   cd /opt/bs-order/web
   npm install                                    # 新增 unplugin-vue-components / unplugin-auto-import
   ```
2. 重新构建并重启：
   ```bash
   npm run build
   systemctl restart bs-order
   ```
3. 新表 `order_template` 会在启动时由 `Base.metadata.create_all` 自动创建；已有库无需手工迁移。若关闭了自动建表，请按 `server/app/models.py` 的 `OrderTemplate` 建表。
4. 访问 `/health`、`/margin`、`/templates` 验证新功能；普通写手账号登录后确认看不到真实价、不能结单/下载非本人订单。
5. Element Plus 已改按需引入，**不要**再在业务代码中全量 `import ElementPlus` 或从 `element-plus` 根包导入 `ElMessage`；按需插件会自动注入。
