# 宝塔面板（Linux）部署指南

系统 = FastAPI 单进程（API + 前端静态托管 + 文件下载）+ MySQL 8 + 可选 Redis，无 Windows 专属依赖，可直接部署到宝塔。本文是宝塔专用步骤；通用公网部署（systemd/无面板）见《部署说明.md》。

> 推荐形态：宝塔只做「Nginx 反代 + HTTPS + MySQL + 计划任务备份」，Python 进程用宝塔的 Python 项目管理器（或 systemd）托管，uvicorn 只监听 127.0.0.1:8000，对外仅开放 80/443。

## 一、软件商店安装

| 组件 | 要求 | 说明 |
|---|---|---|
| Nginx | 任意稳定版 | 反向代理 + HTTPS |
| MySQL | **8.0**（不要用默认 5.7） | 软件商店可切换安装 8.0；建库需 utf8mb4 |
| Python 项目管理器 | 最新 | 可装 Python 3.12；或自行安装 python3.12 也行 |
| Redis | 7.x（可选） | 仅多 worker 部署需要（WebSocket 广播/共享限流） |

系统工具（视频缩略图需要 ffmpeg，可装可不装，缺失时仅无缩略图）：

```bash
# Debian/Ubuntu
apt update && apt install -y ffmpeg
# CentOS/Alma（需要 epel/rpmfusion）
yum install -y epel-release && yum install -y ffmpeg
```

## 二、上传代码

本地打包上传（**不要**上传 `web/node_modules`、`server/.venv`、`server/data/`、`server/backups/`）：

```bash
# 本地（Git Bash）打好要传的目录：server/ + web/dist + .env 模板
# 服务器解压到：/www/wwwroot/bs-order/
```

目录结构（服务器上）：

```
/www/wwwroot/bs-order/
├── .env                  # 从模板新建（见下）
├── server/               # 后端 + 前端构建产物由它托管
│   ├── app/  tests/  scripts/  sql/
│   └── requirements.txt
└── web/dist/             # 前端生产构建（本地 npm run build 的产物；不装 Node 也可以）
```

> 前端直接在本地 `npm run build` 后把 `web/dist` 传上去即可，服务器无需 Node。

## 三、MySQL 建库

宝塔「数据库」→ 添加数据库：

- 名称：`bs_order_system`（或自定义，与 .env 的 DB_NAME 一致）
- 用户名/密码：自定（记入 .env）
- 字符集：**utf8mb4**（建库后可在 phpMyAdmin 确认 collation 为 utf8mb4_unicode_ci）

> `python -m app.init_db` 会自动建表并写入初始品质/设置/管理员，无需手工导 SQL。

## 四、配置 .env

`/www/wwwroot/bs-order/.env`：

```ini
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=bs_order_system
DB_PASSWORD=你的数据库密码
DB_NAME=bs_order_system

PORT=8000
# 生成：python -c "import secrets; print(secrets.token_urlsafe(48))"
JWT_SECRET=改成足够长的随机串（≥32位，绝不使用默认值）

# 启用 HTTPS 后必须 true，否则登录 Cookie 不会下发
COOKIE_SECURE=true

# 经 Nginx 反代必开，否则限流把所有用户当成同一个 127.0.0.1
TRUST_PROXY_HEADERS=true
TRUSTED_PROXIES=127.0.0.1

# 同源部署填正式域名即可
ALLOWED_ORIGINS=https://你的域名

# 备份加密密钥（强烈建议独立生成，见《部署说明.md》）
# python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
BACKUP_ENCRYPTION_KEY=

# 单 worker（单人使用推荐）留空；Python 项目管理器里配了多 worker 才填
# REDIS_URL=redis://127.0.0.1:6379/0
```

## 五、安装依赖并初始化

```bash
cd /www/wwwroot/bs-order/server
python3.12 -m venv .venv
.venv/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
.venv/bin/python -m app.init_db     # 建表 + 初始数据，打印初始 admin 密码（抄下来）
```

目录权限（宝塔进程默认 www 用户）：

```bash
mkdir -p data/uploads backups
chown -R www:www /www/wwwroot/bs-order
```

## 六、常驻运行（两种方式任选）

### 方式 A：宝塔 Python 项目管理器（面板操作）

1. Python 项目管理器 → 添加项目：
   - 名称：`bs-order`；路径：`/www/wwwroot/bs-order/server`
   - Python 版本：3.12（或用项目 venv）
   - 启动方式：`python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`
   - 工作目录必须是 `server/`；**workers 保持 1**（要开多 worker 先配 REDIS_URL）
2. 启动后 `curl 127.0.0.1:8000/api/health` 应返回 `{"ok":true,"version":"1.25.0"}`

### 方式 B：systemd（不依赖面板）

`/etc/systemd/system/bs-order.service`：

```ini
[Unit]
Description=BS Order System (FastAPI)
After=network.target mysql.service

[Service]
Type=simple
User=www
WorkingDirectory=/www/wwwroot/bs-order/server
ExecStart=/www/wwwroot/bs-order/server/.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload && systemctl enable --now bs-order
```

## 七、网站（Nginx 反代 + HTTPS）

宝塔「网站」→ 添加站点（纯静态、不建 FTP/数据库），域名填你的域名，然后「设置 → 反向代理」或直接贴配置（配置文件里 `server` 块）：

```nginx
server {
    listen 80;
    server_name 你的域名;
    # 宝塔申请证书后自动生成 443 块，证书装好建议强制 HTTPS

    # 大文件上传：分片单片 5MB，但直传路径上限 1GB+，直接不限最省心
    client_max_body_size 0;

    # 长连接超时（WebSocket 心跳 30s、大文件下载/上传）
    proxy_connect_timeout 300s;
    proxy_send_timeout 600s;
    proxy_read_timeout 600s;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        # WebSocket（站内通知/私信实时推送）
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_buffering off;          # 大文件下载/视频拖动不落盘缓冲
    }

    # 可选：静态资源让 Nginx 直接发（省一点 Python 进程开销）
    # location /assets/ {
    #     alias /www/wwwroot/bs-order/web/dist/assets/;
    #     expires 30d;
    # }

    access_log /www/wwwlogs/bs-order.log;
    error_log  /www/wwwlogs/bs-order.error.log;
}
```

随后：SSL 证书（宝塔一键 Let's Encrypt）→ 开启「强制 HTTPS」。此时 `.env` 的 `COOKIE_SECURE=true` 才生效。

## 八、备份与升级

**备份**：宝塔「计划任务」每天执行 Shell（保留 14 份，加密落盘到 `server/backups/`）：

```bash
cd /www/wwwroot/bs-order/server && .venv/bin/python scripts/backup.py
```

（可再在系统设置里配 `backup_sync_dir` 指到宝塔的同步目录，实现异地/网盘双备份。）

**上传文件也要备份**：`scripts/backup.py` 只备数据库，不含 `server/data/uploads/` 里的交付物（视频、程序包）。宝塔「计划任务」→ 添加「备份目录」，目录填 `/www/wwwroot/bs-order/server/data/uploads`，每天执行、保留 7 份（与 03:30 的数据库备份错开，例如 03:50）。注意：替换或删除文件会直接清掉磁盘上的旧文件，误操作只能从这份备份找回。

**升级代码**：替换 `server/` 与 `web/dist/` → 重启进程即可。老库无需手工迁移：启动时会自动建缺失表、补新列（如 `project_type`、`source_apply_mode`）并回填历史数据；`sql/` 下的脚本仅作兜底。

## 九、常见坑（按踩中概率排序）

1. **登录不上、一直 302**：HTTPS 已启用但 `.env` 忘了 `COOKIE_SECURE=true`（或反过来：HTTP 访问却开了 true）。
2. **上传大文件 413**：Nginx `client_max_body_size` 没放开（宝塔默认 50MB）。
3. **所有人共享一个限流桶**：反代了但没开 `TRUST_PROXY_HEADERS=true`。
4. **MySQL 装成 5.7**：请用 8.0；5.7 未经测试且字符集行为有差异。
5. **多 worker 没配 Redis**：WebSocket 通知时有时无、限流计数不共享——单人使用直接 1 worker 最稳。
6. **单号日期/日历差一天**：服务器时区不是东八区 → `timedatectl set-timezone Asia/Shanghai`。
7. **视频没缩略图**：服务器没装 ffmpeg（功能不受影响，仅缩略图缺省）。
8. **安全组/防火墙**：只放行 80/443；8000 只绑 127.0.0.1，不要对公网开放。
9. **数据迁移**：从 Windows 迁移历史数据时，用旧库的备份脚本导出加密备份 → 服务器 `scripts/restore_backup.py` 恢复，并把整个 `server/data/uploads` 目录原样拷贝（文件与数据库记录一一对应）。
